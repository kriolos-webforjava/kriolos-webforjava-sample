== Overview

`kriolos-opos-webforj-quarkus` is a modern, enterprise web application built on **Quarkus 3** and **webforJ 26.02**, powered by the **`quarkus-webforj`** extension.

It brings together the reactive, lightweight architecture of Quarkus (Undertow HTTP/WebSocket engine, CDI/Arc, built-in security) with the server-driven UI component model of webforJ (Digital Web Client - DWC, OKLCH color engine, and rich UI widgets).

== Prerequisites

* **Java 21** or newer
* **Maven 3.9+** (or use the included `./mvnw` Maven Wrapper)
* **Firefox** (installed automatically via Playwright for browser testing)

== Getting Started

=== Development Mode (Live Coding)

To run the application with Quarkus dev mode and live reload enabled:

[source,bash]
----
./mvnw quarkus:dev
----

Once launched, access the application at:
* **Application**: http://localhost:8080
* **Quarkus Dev UI**: http://localhost:8080/q/dev/

=== Live Coding & Hot Reload
With `quarkus-webforj`, Quarkus monitors your Java source files and webforJ components. Simply edit code in your IDE, save the changes, and refresh the browser—Quarkus automatically compiles and updates classes on the fly without requiring server restarts or external hotswap agents.

== Testing

=== Running Unit Tests
Run standard JUnit 5 tests:

[source,bash]
----
./mvnw test
----

=== Running Integration Tests
Run end-to-end integration tests using the Maven Failsafe Plugin (`*IT.java`):

[source,bash]
----
./mvnw verify
----

=== Multi-Browser Concurrent & Load Testing
The project includes an advanced multi-browser concurrent test harness (`MultiBrowserFirefoxTest`) simulating realistic human user personas (Short-Lived, Mid-Lived with multi-tab, and Long-Lived sustained connections):

[source,bash]
----
# Run 1 standard cycle with 10 unique users
./mvnw test-compile exec:java \
  -Dexec.mainClass="io.github.kriolos.opos.MultiBrowserFirefoxTest"

# Run a 2-hour stress test with 20 parallel browsers
./mvnw test-compile exec:java \
  -Dexec.mainClass="io.github.kriolos.opos.MultiBrowserFirefoxTest" \
  -Dtest.duration=2h -Dtest.parallel.count=20
----

For complete details on configuring duration, personas, multi-tab behavior, and interpreting performance reports, see:
* link:src/test/java/io/github/kriolos/opos/MultiBrowserFirefoxTest.adoc[Multi-Browser Test Manual (`MultiBrowserFirefoxTest.adoc`)]

=== Playwright Linux Dependencies
If running in a fresh Linux or CI/CD environment:

[source,bash]
----
# Install missing system libraries if needed
sudo apt-get update && sudo apt-get install -y libavif16 libwoff1

# Install Playwright browser dependencies
mvn exec:java -e -Dexec.mainClass=com.microsoft.playwright.CLI -Dexec.args="install-deps"
----

== Building for Production

To package the application for production deployment:

[source,bash]
----
./mvnw clean package
----

This creates the optimized Quarkus fast-jar distribution in `target/quarkus-app/`:

[source,bash]
----
java -jar target/quarkus-app/quarkus-run.jar
----
